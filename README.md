# Student Performance Analysis 📊

A Python project that analyzes student academic performance using Pandas and Matplotlib.

## About the Project

This project analyzes student marks, calculates percentages, summarizes class performance, and generates a visualization.

## Features

- Calculate total marks for each student.
- Calculate student percentages.
- Classify student performance.
- Calculate class average.
- Identify the highest and lowest percentages.
- Export results to a CSV file.
- Generate a performance chart.

## Technologies Used

- Python
- Pandas
- Matplotlib
